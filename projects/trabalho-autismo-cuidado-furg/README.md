# Trabalho, Autismo e Cuidado na FURG

Projeto institucional multicampi para articular apoio entre pares, formação de gestores e recursos educacionais sobre trabalho, autismo e responsabilidades de cuidado na comunidade FURG.

## Estado atual

Minuta técnica estruturada para validação institucional. O projeto integral tem vigência proposta de doze meses; o piloto inicial está concentrado entre setembro e dezembro de 2026. Datas, unidade gestora, equipe, cargas horárias e classificação no SisProj ainda precisam de confirmação.

## Componentes

1. **Trilha de pares:** espaços formativos entre servidores autistas e servidores que cuidam de pessoas autistas, com apoio inicial para alcançar autonomia e sustentabilidade.
2. **Trilha de gestão:** formação prática para chefias e equipes sobre acolhimento, acessibilidade, organização do trabalho, limites funcionais e encaminhamentos.
3. **Repositório educacional:** materiais públicos, acessíveis, revisados e versionados para toda a comunidade.
4. **Governança e avaliação:** papéis delimitados, proteção de dados, indicadores agregados e revisão por fases.
